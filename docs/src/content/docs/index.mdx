## What is it

It is a small ui framework library build with [clay](https://github.com/nicbarker/clay) and
[raylib](https://github.com/raysan5/raylib), for [Odin](https://odin-lang.org).

The whole library is one package: `kiln`. Apps import it once (no raylib, no clay) and write
their UI as plain procs with `if` blocks:

```odin
import "lib:kiln"

view :: proc(m: ^Model, out: ^[dynamic]Msg) {
	if kiln.card("Profil") {
		if t, ok := kiln.text_field(m.name, "Name"); ok {append(out, Set_Name{t})}
		if kiln.submitted() {append(out, Save{})}

		if v, ok := kiln.slider(m.volume, 0, 100); ok {append(out, Set_Volume{v})}

		if kiln.actions() {
			if kiln.button("Löschen", .Danger) {kiln.show("confirm")}
			if kiln.button("Speichern") {append(out, Save{})}
		}
	}
}
```

## What you get

<CardGrid>
  <Card title="Controlled widgets" icon="pencil">
    Widgets take the current value and return `(new_value, changed)`. The view never writes to the
    model.
  </Card>
  <Card title="Elm style app loop" icon="random">
    `init`, `update`, `view`. Messages go in, the model changes in one place.
  </Card>
  <Card title="Responsive" icon="laptop">
    `grid`, `adaptive`, `field`, `actions`, `table` and `dialog` adapt to the space they get.
  </Card>
  <Card title="Snapshots" icon="seti:image">
    Render the app headlessly into PNGs at phone, tablet and desktop size.
  </Card>
</CardGrid>
